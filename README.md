# 以太残响 · Aether Fragment

一款原创的浏览器炼金解谜游戏。你扮演残响解析者，沿着遗物和研究笔记追踪逐渐枯竭的灵气场。

## 开始游戏

使用 Node.js 22.12 或更新的 LTS 版本。在项目根目录运行 `npm ci`，再运行 `npm run dev`，打开终端显示的本地地址。进度按浏览器站点地址保存在本地。

运行 `npm run build` 生成 `dist/`，可用 `npm run preview` 预览生产版本。前端采用 Phaser 3、TypeScript 和 Vite。浏览器测试可用 `npx playwright test` 运行，详细流程见 [AGENTS.md](AGENTS.md)。

- **研究台**共有 16 章。把要素拖到空格，或先点击库存再点击空格。相邻的复合要素与其直接成分会连线。所有金边锚点连通后提交研究。
- **解析台**能从遗物逐份揭示要素。**合成与图鉴**可在合成台试配已开放的配方。
- **灵气场**可抽取要素、培育纯净节点或静置调墨。枯竭的节点永久关闭。
- **注魔台**用两对对称的要素降低事故风险。腐化累积后可以前往**腐化事件**处理残渣或选择如何应对裂隙。
- **行旅驿站**有角色立绘与对话框，点选问题即可交谈。用研究与擂台首胜获得的潮印购买墨水和要素，也可出售残渣。
- **回响擂台**有三位对手。开战前从库存任意搭配恰好 8 份要素，演练结束或退出后退回未消耗的要素。携带用尽后，每场最多从研究库存再调用 3 份。脉冲消耗固定数量，共鸣和回护可在各自的范围内调整消耗，交织需要两种不同的要素。首胜奖励只领取一次。
- **角色选择**提供战斗、研究和探索三类角色，均可出战。陆砚提高攻击法术的威力和命中率，还能以护盾换取额外威力。闻汐能读阵、从研究多获要素、查看合成成功率和对手要素明细，并且每场可回收一份材料。桑铃擅长折价和降低旅行风险，祁渡能提高考察产量，两人都可以夺取对手要素。演练进行中无法换人。
- **旅行**有三条随研究开放的考察路线。每条路线提供不同的剧情选项、要素产出和腐化代价。每个研究进度最多完成两次考察，同一路线只算一次。
- **武器库**共有八件 3★、4★、5★ 武器，各角色独立保存装备。初始开放两件 3★ 武器，其余通过研究、演练或旅行解锁。任意角色都能装备 5★ 武器并获得基础属性，对应角色才能激活专属效果。演练开始后装备固定到该场结束。

研究格支持键盘操作。用 Tab 移动焦点，按 Enter 或空格放置，按 Delete 或 Backspace 撤回。触屏支持点选。

`world.js` 定义世界与研究阵图，`game.js` 处理游戏状态与交互，`encounters.js` 实现对话、交易和演练，`combat-skills.js` 定义技能和消耗规则，`travel.js` 定义旅行剧情与奖励，`weapons.js` 定义装备、解锁和专属效果。
